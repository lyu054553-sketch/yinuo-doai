# 衣诺下一阶段开发地图

目标：完整满足上服赛题，再用可追溯的需求审计、版本管理与人工复核形成差异化。当前比赛原型、两套完整模拟案例、交付文档和本机演示环境均已形成。

## 版本与评测边界

- D2 是旧快照的正式成绩；D3 是冻结快照 `7b4d0edb74aceff48a21b75555f0e56593a8619fce6bb7ce06e4a8f93947af44` 的一次性留出结果。原始记录与锁永久保留。
- 新开发属于下一版本，不覆盖旧结果；案例五已经揭晓，不能再作为未见留出集。新的效果结论需独立、业务人员审核的新数据和新评测方案。
- 所有资产仅为现有模拟案例参考；资料缺失时明确标注，不编造库存、职业服资源、适用场景或工艺规范。

## 里程碑与验收

当前进展：第 1–5 项已具备当前原型交付证据；第 6 项的外部入口已停用，防护设计保留为历史方案；第 7 项已落地逐句审计、仅问改变方案的问题、版本影响追踪、参考图冲突提醒和人工复核，但独立专家数据和正式对照评测仍属于试点阶段。逐项证据见 [最终验收清单](最终验收清单.md)。

1. **资产知识库（已完成当前原型验收）**：43 项分类目录，其中 40 项可进入推荐；支持类型、风格、场景筛选、来源与使用规范、缺失字段和 CSV 导出。
2. **六维需求报告（已完成当前原型验收）**：真实模型生成官方六维、情绪审美、场景、人群共九维结果；引用原话校验、人工核对、修正说明与修订历史均已实现。
3. **方案与适配说明（已完成当前原型验收）**：方案覆盖风格、面料、版型、工艺、场景、人群、色彩纹样松量、亮点、资源规范与可行性，资源不足时明确标待补。
4. **视觉需求包与业务台账（已完成当前原型验收）**：三类提示词按版本生成，多件套所有件同框；CSV/JSON v2 台账与浏览器导出一致。
5. **完整交付（已完成当前原型验收）**：两套真实模型模拟案例、架构/业务/落地/风险/能力边界文档、最终验收矩阵和文件哈希清单已形成。
6. **受保护外部测试环境（历史方案，入口已停用）**：独立存储、HTTP Basic、同源写检查、请求大小限制和内存调用配额已实现并做过临时环境验收；当前演示改用本机环境，不再依赖外网链接。
7. **试点强化（仍需外部专家和新数据）**：继续用独立专家标注数据、对照组及误报漏报检验当前版本；不能把 D2/D3 旧数字当作新版本未见测试。

## 当前已知限制

- D2 注入问题：衣诺 32/54，通用问法 33/54，未证明检出优势。
- D3 单次案例五无标准问题句，问题检出为 0/0，无法证明泛化。
- 视觉模型将案例六交领误识别为立领；此项仍需人工复核。衣长、廓形和颜色不采用模型判断。
- 此前的临时外网入口已失效，当前演示使用本机环境（后端 8100、前端 5173），不依赖外部链接；本机演示尚无固定域名、正式高可用部署和多用户账号隔离。
- 九维语义归类的两套完整案例均有人工核对，但样本量小，不能据此宣称普适准确率。
