## 原型代码入口

- 后端：`backend/app/`，FastAPI 会话、需求解构、资源目录、方案、媒体与台账接口。
- 前端：`frontend/src/`，React/TypeScript 工作台与资源知识库。
- 自动测试：`backend/tests/`、`eval/`、`orchestration/test_test_gateway.py`、`orchestration/test_worker.py`。
- 启动：`orchestration/start_backend.py`、`orchestration/start_vision.py`、`orchestration/start_test_gateway.py`。
- 浏览器验收：`orchestration/check_current_delivery.py`、`orchestration/check_team_delivery.py`。
- 外网验收：`orchestration/check_external_delivery.py`。

## 数据与运行边界

- `data/` 是比赛模拟静态数据，不对接生产系统、真实库存、供应商或报价 API。
- `orchestration/runs/` 是本地运行数据和凭据目录，按 `.gitignore` 不提交。
- `frontend/dist/` 是可由 `npm run build` 重新生成的生产构建，不提交。
- 当前没有付费生图调用；三类视觉提示词与外部图片核对能力保留。视觉服务在本机运行，依赖环境放在 iCloud 同步目录之外。
