## 数据和访问边界

- 当时的测试后端使用 `orchestration/runs/external-test/final-storage-20261119/`，预置两套脱敏模拟案例，不读取本机其他洽谈记录；测试者共用该测试环境及后续新记录，不同测试者之间没有账号隔离。
- 当时的测试入口使用 HTTP Basic 凭据，必须通过 HTTPS 访问；凭据只保存在本机运行目录，文件权限 600，不进 Git，也不写入文档或提交材料。
- 网关对新建会话、参考图和效果图上传设置累计 20 次请求上限；上限统计是单进程内存计数，重启会重置，并非精确的模型调用费用上限。仅用于小范围测试，真实费用仍由网关计量。
- 仅允许同源的写请求，限制上传大小；未授权请求返回 401。即使重新建立入口，也不能把它视为经安全审计的生产环境。
- 仅使用模拟数据；导出文件包含输入原话和会话记录，应按测试资料管理。接口和原始模型结果都可能包含误判，须由人复核。

## 启动与检查

```sh
# 1. 视觉服务；保持本机模型与数据可用
python3 orchestration/start_vision.py

# 2. 独立测试后端，使用本机 Magpie 和独立目录
python3 orchestration/start_backend.py --port 8102 --storage-dir orchestration/runs/external-test/storage

# 3. 前端生产构建及带密码的本地网关
cd frontend && npm run build && cd ..
python3 orchestration/start_test_gateway.py
```

视觉服务的依赖环境需建在 iCloud 同步目录之外（见 `orchestration/start_vision.py` 顶部说明）；其余步骤用于复现当时的网关防护，不对外提供入口。

只启动缺失的服务，避免同一端口重复启动。三项检查：本机网关未带凭据访问返回 401；带凭据的 `/api/health` 表示 `mock_mode=false`、模型为指定的 DeepSeek；创建新的模拟会话，确认语义分析、写入和三类提示词。不得再次把案例五当作未见测试案例。

## 已知限制（当时）

当时的临时隧道由 Cloudflare 提供，不保证可用性；测试只验证当时的环境，尚无独立安全审计、正式域名、访问管理、自动备份、持久化配额和多用户隔离。外部模型请求可能产生费用；没有配置付费生图。正式比赛入口若需要长期、多人或稳定访问，应另行部署受保护的持久服务并验证预算和可恢复性。
