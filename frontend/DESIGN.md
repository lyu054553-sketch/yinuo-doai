# 衣诺前端视觉与交互规范

> 供实现使用，只规定界面与交互，不改变接口和业务逻辑。目标：白纸、墨色、克制的服饰档案质感；业务工具优先，不做数据大屏。

## 1. 原则
- 白色文档、细分隔线、充分留白；无大面积渐变、玻璃拟态、插画、花哨图表、悬浮卡片墙。
- 墨色承担品牌、选中、版本与操作；状态色仅表示对应状态，不作装饰。
- 不使用大型 UI 库、外部素材、在线字体；图标用自绘 16/20px SVG，非常见图标附中文。
- 正文不小于 14px；原话、方案值、理由完整换行，不以省略号掩盖。

## 2. 令牌
```css
--canvas:#F5F3EE; --paper:#FFF; --warm:#FCFBF8;
--ink:#22231F; --ink-2:#575850; --muted:#6D6B63;
--line:#DDD9D0; --line-strong:#B8B2A7; --hover:#F3F1EC; --selected:#EAE8E1;
--disabled:#EBE9E3; --disabled-text:#817C73;
```
- 面板白底、1px `line`、6px 圆角、无阴影；按钮/输入框 4px，标签 2px。
- 主按钮墨底白字；次按钮白底墨边；链接墨色下划线，不用装饰蓝。
- 无出处：白底、2px 墨边、`!` 和“无出处”，不得借状态色。
- 错误 `#96372F` 并配图标、文字；成功用墨色对勾；核对结论均显示文字，不只靠颜色。

## 3. 七种状态
|状态|文字/下划线|浅底|原话线型|
|---|---|---|---|
|有冲突|#96372F|#FBEDEA|3px 双线 + !|
|被改写|#874A18|#FFF2E5|2px 虚线|
|未落实|#735900|#FFF7DC|2px 点线|
|需设计师判断|#664B7B|#F4EFF7|2px 波形线 + 菱形|
|间接体现|#385D76|#EDF3F6|1px 实线|
|已落实|#316047|#EDF5EF|2px 实线|
|已与客户确认|#245B56|#EAF3F1|3px 实线 + 锁标|
- 状态徽标同时显示完整中文；圆角 2px、12px/18px、内边距 3px 7px。
- 原话下划线距字底 5px；默认不铺整段底色。方案锁标、本版变更均用中性墨色。

## 4. 字体、间距、控件
- 字体：`PingFang SC, Microsoft YaHei, Noto Sans CJK SC, Source Han Sans SC, sans-serif`；id/版本数字可用系统等宽字体。
- 品牌 24/32、会话标题 17/26、栏标题 16/24、原话 16/32、方案值 15/26、审计与选项 15/25。
- 正文/按钮/输入 14/22；仅时间、id 等元信息 12/20。中文不强制斜体。
- 间距采用 4/8/12/16/20/24/32/40px；面板内边距 16px，原话区 20px，大分区 24px。
- 主按钮高 40px；紧凑按钮 36px；选项最小高 44px；输入最小高 40px；图标点击区至少 40×40px。

## 5. 1440×900 工作台
- 顶栏 `0,0,1440×72`；主区上/下各 20px、左右各 24px。
- 三栏均 `y=92，高788，底边880`：左 `x=24，w384`；中 `x=424，w472`；右 `x=912，w504`；栏间距 16px。
- 高度采用 `calc(100dvh - 112px)`；不足 600px 时页面纵向滚动，不裁内容。
- 三栏独立滚动；栏头 52px sticky。右栏页签另高 48px sticky，正文 688px；滚动条稳定占位。
- 顶栏依次为品牌“衣诺”、会话标题/模式/来源、醒目的“方案 vN”、返回列表；长标题省略但版本不消失。
- 1280 宽：外边距 16px、栏间距 12px，栏宽按 `31% / 34% / 35%` 分配，最小宽约 330/390/410px；窄屏依次纵向堆叠，禁止横向挤压。

## 6. 三栏内容
- 左栏：编号“01 客户原话”；原文连续排版，片段带状态线下划线。参考图置底，图片等比完整显示；识别项标“疑似/请人工确认”，未采用项写“模型结果未采用”，冲突可跳原话。
- 中栏：编号“02 需求落实审计”；七状态以可换行文字筛选签统计，不做图表。默认按严重程度、同级按原文位置排序。
- 审计条含状态、强度、原话、字段/单品、理由；整行可选。问题含背景、为什么问和整行选项；已回答保留所选及原因，提交中禁用并写“正在记录客户选择…”。
- 设计师事项、不问清单依次置后，有原因和空状态；不折叠隐藏关键风险。
- 右栏：编号“03 方案档案”及紧凑版本；固定页签“方案/效果图/台账/交接单”，激活用 2px 墨线。
- 八字段顺序固定；每项含值、origin、资源出处、修改入口、确认锁标。本版变更用中性浅底、3px 墨线和“本版变更”。
- 修改在当前字段内展开，含方案值、必填原因、保存/取消；失败保留输入。已确认字段提示会形成新版本。
- 台账倒序，显示时间、版本、动作、摘要、原因、变化字段；交接单支持复制，正文 15/28，宽表仅内部横滚。

## 7. 原话映射联动
1. 点击左原话或中审计项，记录 utterance id；两处同步为中性底/墨框并暴露选中语义。
2. 右栏切到“方案”，按 mappings 高亮全部对应字段；滚动至首项，使用 `block:nearest`。
3. 字段使用该 mapping.status 的浅底和 3px 状态线，附“来自原话 uN”及 note；其他字段不降透明度。
4. “本版变更”标签继续保留；编辑态以 2px 墨框优先，版本提示播完恢复映射高亮。
5. 再点已选原话、点“清除映射”或 Esc 清除；不得改方案、不得靠字段名猜映射。

## 8. 动效、加载、空态、错误
- 成功响应后才升版本；版本数字 160ms 淡入，改动字段底色 1200ms 由 `selected` 过渡至白，标签持续保留。
- hover/选中 120ms；滚动 200ms；不用弹跳、缩放整栏、粒子、自动轮播。请求中不伪造成功。
- 新建洽谈显示可跳过/可等待的步骤文字，如“正在拆分客户原话…”，不伪造百分比；按钮保持宽度。
- 局部加载用中文和 3 条中性骨架线；整页加载保留顶栏骨架，不空白、不闪烁。
- 空态含明确标题、一句说明和主操作，如“暂无洽谈记录/新建洽谈”；筛选为空提供“查看全部”。
- 错误直接展示后端 error，靠近出错区域；保留上下文并提供重试。网络失败写“连接中断，请检查服务后重试”，不显示堆栈。
- 501 显示“该功能开发中”；视觉 503 仅禁用相关区域，其余工作流可用。

## 9. 键盘与降低动效
- 使用原生按钮、输入、页签语义；Tab 顺序与视觉一致，Enter/Space 激活，方向键切换页签/单选，Esc 清映射或取消编辑。
- 焦点为 `2px #22231F` 外环 + `2px #FFF` 间隔，offset 2px；不得去除焦点或仅改底色。
- 跳转长列表后焦点移到目标标题但不突然抢输入焦点；弹层若使用需焦点圈定、关闭归还。
- `@media (prefers-reduced-motion:reduce)`：动画/过渡近零、滚动 auto；保留静态高亮、标签和状态文字。
- 响应式与缩放 200% 仍可操作；禁用、加载、错误均有文字和可访问名称。
